 airline-reservation-system

SkyIndia is a **Java-based Airline Reservation System** that provides a complete flight booking experience through a modern and interactive desktop application. It allows users to search and book flights, choose seats and passenger services, manage trips, and access booking-related features through an intuitive interface.

**Technologies Used** : Java Swing, OOP, File Handling, Object Serialization, Collections Framework, Java Time API, Java 2D Graphics

**Features:**
-One-way, Round-trip & Multi-city Booking
-Connecting Flights & Layover Details
-Smart Flight Search, Sorting & Filtering
-Saver, Flex & Premium Fare Options
-Interactive Seat Selection
-Baggage & Meal Selection
-Promo & Referral Codes
-Booking Modification & Cancellation
-SkyPoints & Rewards
-Saved Routes & Price Alerts
-E-Ticket & Booking Confirmation
-Booking History & Trip Management
